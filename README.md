# unity-loop-page

Project page for [zozo123/unity-loop](https://github.com/zozo123/unity-loop) — vibe-coded Unity on islo.dev sandboxes.

Live: https://zozo123.github.io/unity-loop-page/

This repo is just the static landing page. The code, orchestrator, and writeup live in the main repo.

Champion state is fetched from `unity-loop/runs/champion.json` on every page load — when the loop promotes a new variant, this page reflects it within a few seconds (no rebuild needed).
